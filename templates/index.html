{% if mode == "divider" %}

สูตรที่ใช้ · Thevenin base divider

VBB = VCC · R2 / (R1 + R2)
RB  = R1 ∥ R2
IB  = (VBB − VBE) / (RB + (β + 1)·RE)
IC  = β·IB
IE  = (β + 1)·IB
VE  = IE·RE
VB  = VE + VBE
VC  = VCC − IC·RC
VCE = VC − VE
{% elif mode == "fixed" %}

สูตรที่ใช้ · Fixed Bias

IB  = (VCC − VBE) / RB
IC  = β·IB
IE  = (β + 1)·IB
VE  = 0 V
VB  = VBE
VC  = VCC − IC·RC
VCE = VC
{% else %}

สูตรที่ใช้ · Emitter Bias

IB  = (VCC − VBE) / (RB + (β + 1)·RE)
IC  = β·IB
IE  = (β + 1)·IB
VE  = IE·RE
VB  = VE + VBE
VC  = VCC − IC·RC
VCE = VC − VE
{% endif %}
