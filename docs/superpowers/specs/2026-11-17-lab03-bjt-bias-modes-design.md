# Lab 03 — เพิ่มโหมด Fixed Bias และ Emitter Bias ในเว็บ BJT DC Bias

วันที่: 2026-11-17
สถานะ: อนุมัติแนวทางแล้ว (ผู้ใช้สั่ง "ลุย")

## ทำไม

ใบงาน ENG29 2121 Lab 03 ต่อยอดเว็บ Flask จาก Lab 2 ให้เลือกวงจรไบอัสได้สามแบบ
คือ Voltage Divider Bias (ของเดิม), Fixed Bias และ Emitter Bias แบบแหล่งจ่ายเดียว
โดยผลของ Divider ต้องคงเดิมเมื่อกรอกค่าเดิม และต้องตรวจผลจริงผ่านเบราว์เซอร์

## เป้าหมาย

- `bjt.py` มีฟังก์ชันคำนวณ Fixed Bias และ Emitter Bias แยกกันตามสมการใบงาน
  และคงวิธีคำนวณ Divider เดิมไว้ทั้งหมด
- `app.py` เลือกฟังก์ชันตาม `mode` ด้วย `if/elif` แปลงหน่วยและตรวจเฉพาะช่องที่โหมดนั้นใช้
  โหมดที่ไม่รู้จักต้องแจ้งข้อผิดพลาด ไม่เดาเป็น Divider
- `templates/index.html` เลือกโหมดแล้วโหลดฟอร์มใหม่ได้โดยไม่ใช้ JavaScript
  แสดงเฉพาะช่องที่โหมดนั้นใช้ ผลลัพธ์ระบุโหมด และอินพุตผิดต้องไม่ค้างผลรอบก่อน
- `README.md` อัปเดตวิธีรัน/คุณสมบัติ และ `docs/validation.md` มีตาราง A1–A5
  พร้อมค่าอ้างอิงที่คำนวณแยกจากโค้ดโปรแกรม
- unittest เดิมทั้งหมดยังผ่าน (ไม่เพิ่ม unittest ใหม่ตามขอบเขตใบงาน)
- ตรวจ A1–A5 ผ่านเบราว์เซอร์จริงและบันทึกผล

## สิ่งที่ไม่อยู่ในขอบเขต

- ไม่ทำ SPICE, DC Load Line, AC/Transient, Bypass capacitor
- ไม่เปลี่ยนหน่วยฟอร์มจาก Ω เป็น kΩ (ใบงานระบุว่าใช้ได้ถ้าฟอร์มเดิมเป็น Ω)
- ไม่เพิ่ม JavaScript framework, ไม่ทำ nodal cross-check สำหรับโหมดใหม่
- ไม่ push ขึ้น GitHub (commit local เท่านั้น)

## ทางเลือกที่พิจารณา

1. **dataclass + ฟังก์ชันแยกตามโหมด (เลือกใช้)** — `BiasInputs` เดิมสำหรับ Divider,
   เพิ่ม `FixedBiasInputs` และ `EmitterBiasInputs` พร้อมฟังก์ชันคำนวณของตัวเอง
   ข้อดี: สมการอ่านตรงใบงาน, ตรวจชนิดข้อมูลได้, ไม่กระทบเทสต์เดิม
   ข้อเสีย: มีโค้ดคำนวณผลส่วนท้ายซ้ำบ้าง (แก้ด้วย helper ร่วม)
2. dataclass เดียวที่มีฟิลด์เป็น optional + ธงโหมด — เขียนน้อยกว่า แต่เสี่ยงลืมฟิลด์
   และทำให้ `BiasInputs` เดิมซึ่งมีเทสต์อ้างอิงต้องเปลี่ยน
3. ฟังก์ชันเดียวรับ `mode` แล้วเลือกสูตรข้างใน — ง่ายต่อ route แต่รวมสมการสามชุดไว้ที่เดียว
   ทำให้ตรวจสอบยากขึ้นและใบงานต้องการให้แยกฟังก์ชัน

## การออกแบบ

### โมดูลคำนวณ (`bjt.py`)

- ค่าคงที่ `MODE_DIVIDER = "divider"`, `MODE_FIXED = "fixed"`, `MODE_EMITTER = "emitter"`
  และ `MODES` สำหรับตรวจค่า
- `validate_inputs(raw)` เดิมคงไว้สำหรับ Divider (เทสต์อ้างอิงอยู่)
- เพิ่ม `validate_fixed_bias(raw)` และ `validate_emitter_bias(raw)`
  ใช้ helper ร่วมในการแปลงตัวเลข ตรวจจำนวนจำกัด ขอบเขต 1e12 และค่าบวก
  โดยตรวจเฉพาะฟิลด์ที่โหมดใช้: common = `vcc, rc, beta, vbe`;
  Fixed เพิ่ม `rb`; Emitter เพิ่ม `rb, re`
- `calculate_fixed_bias(inputs)`:
  `IB = (VCC − VBE) / RB`, `IC = βIB`, `IE = (β+1)IB`, `VE = 0`,
  `VB = VBE`, `VC = VCC − IC·RC`, `VCE = VC`
- `calculate_emitter_bias(inputs)`:
  `IB = (VCC − VBE) / (RB + (β+1)RE)` แล้วใช้สมการผลลัพธ์ชุดเดียวกับ Divider
- helper ร่วมสำหรับสร้าง `OperatingPoint` จาก `IB` (คำนวณ IC/IE/VE/VB/VC/VCE,
  จำแนก region, หา `IC(sat)`) เพื่อไม่ให้สูตรผลลัพธ์แตกกัน
  - Fixed: `IC(sat) = (VCC − 0.2) / RC`
  - Emitter/Divider: `IC(sat) = (VCC − 0.2) / (RC + RE)`
- ตัดสินใจ: `OperatingPoint` เดิมใช้ต่อทุกโหมด โดย Fixed/Emitter ตั้ง `vbb_v = VCC`
  และ `rb_ohm = RB` (ฟิลด์ VBB ไม่แสดงในผลของสองโหมดนี้)

### Flask (`app.py`)

- `MODE_DEFAULTS` แยกค่าเริ่มต้นของแต่ละโหมด; Divider ใช้ `DEFAULTS` เดิมทุกค่า
  (Fixed: `rb = 1000000`; Emitter: `rb = 1000000, re = 1000`)
- GET: อ่าน `?mode=` (ค่าเริ่มต้น `divider`) ถ้าโหมดไม่รู้จักแสดง error ที่ฟอร์ม
  แล้วใช้ค่าเริ่มต้นของโหมดนั้น
- POST: อ่าน `mode` จากฟอร์ม เก็บค่าที่ส่งมาเฉพาะฟิลด์ของโหมด
  เรียก validator ตามโหมด แล้วเรียกฟังก์ชันคำนวณตามโหมดด้วย `if/elif`
- เรียก nodal comparison เฉพาะ Divider; โหมดใหม่ส่ง `comparison = None`
- คงชื่อ `calculate_operating_point` และ `calculate_nodal_operating_point`
  ที่ route เรียกใช้ เพื่อให้เทสต์เดิมที่ patch ชื่อเหล่านี้ยังทำงาน

### ฟอร์ม (`templates/index.html`)

- เพิ่ม `<select name="mode">` และปุ่ม "เปลี่ยนโหมด" ที่ใช้ `formmethod="get"`
  ฟอร์มเดียวกับปุ่มคำนวณ ค่าที่กรอกจะถูกส่งไปทาง query เพื่อคงค่าเมื่อสลับโหมด
- แสดงเฉพาะช่องของโหมด: common + (`r1, r2, re` | `rb` | `rb, re`)
  ตั้ง `required` เฉพาะช่องที่แสดง
- ผลลัพธ์มีป้ายชื่อโหมด, ตารางแสดง `RB` ทุกโหมด, `VBB` เฉพาะ Divider,
  และแสดงส่วน nodal comparison เฉพาะเมื่อมี `comparison`
- ส่วนสูตรด้านล่างเปลี่ยนตามโหมด
- ฟอร์มที่ส่งผิดต้องไม่แสดงผลของรอบก่อน (ส่ง `result = None` เมื่อมี error)
